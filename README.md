# Ty's Portfolio

This repository contains the source code for Ty Flannagan's personal portfolio website. The site showcases Ty's skills as a Developer and Analyst through a visually engaging and interactive design.

## Live Demo

[View Ty's Portfolio](https://tyflannagan.tech/)

## Features

- Responsive design that works on desktop and mobile devices
- Interactive space animation background using Three.js
- Animated text effects using Anime.js
- Custom modal system for displaying content
- Integration with Font Awesome for icons
- Custom Google Font (Amatic SC) for a unique typography style

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- [Three.js](https://threejs.org/) for 3D animations
- [Anime.js](https://animejs.com/) for text animations
- [Font Awesome](https://fontawesome.com/) for icons
- [Google Fonts](https://fonts.google.com/) for typography
- [Lucide](https://lucide.dev/) for additional icons
- [Simplex Noise](https://github.com/jwagner/simplex-noise.js/) for generating smooth random noise
